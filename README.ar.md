# HabitStreak

A habit tracking app with daily check-ins, streak counters, monthly calendar heatmap, stats dashboard, light/dark mode toggle, and localStorage persistence. Categories: Health, Productivity, Mindfulness, Social.

</div>

## البدء السريع
```bash
git clone https://github.com/mayakilzy/habitstreak-app.git
cd habitstreak-app
npm install
npm run dev
```
